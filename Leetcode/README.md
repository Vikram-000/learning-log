## Folder Structure

Problems are organized by their primary topic.

```text
leetcode/
├── Arrays/
├── Strings/
├── Hash_Map/
├── Stack/
├── Linked_List/
├── Trees/
├── Binary_Search/
├── Dynamic_Programming/
├── Graphs/
└── README.md
```

Each solution is named using the LeetCode problem number followed by the problem name.

Example:

```text
0001_Two_Sum.py
0020_Valid_Parentheses.py
0206_Reverse_Linked_List.py
0704_Binary_Search.py
```
