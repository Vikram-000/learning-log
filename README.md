# Learning Log

Daily Python / DSA practice. Not a product, not a portfolio piece — just a running record of exercises and problems solved while learning.

## Structure

```
learning-log/
├── Leetcode/            # DSA problems, organized by topic
└── Practice Projects/   # Small standalone scripts used to learn new concepts
```

Each folder is self-contained. Nothing here is production code, and nothing is meant to run as a single app — treat each file/subfolder as an independent exercise.

## Why this exists

Part of a self-teaching routine: DSA practice first (daily), then a small applied build to lock in whatever concept was just learned. This repo is the DSA + concept-practice side of that routine — the actual product work happens in a separate repo.

## Status

Actively updated. No releases, no versioning — it's a log, not a package.
